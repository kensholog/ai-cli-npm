### 4. 算術上の分解（仮定つき）

Codex CLI の npm 36.35 倍 = 数え方 2.06 × issue 作成者の伸び 6.83 × **残り 2.58**。数え方の係数は直近 7 日の割合が 8 月にも当てはまると仮定し、issue 作成者を「人」の代理に置いた算術で、因果の分解ではない。残りの 2.6 倍の中身（CI での利用の増加、npm 以外から npm への経路の移動、版の数だけ取得するミラーなど）は、公開データでは分けられない。
