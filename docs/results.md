| 区分 | キー数 | ダウンロード数 | 割合 |

**s = 0.5147**（0.40 以上で支持。理論値 0.5）。プラットフォーム版の内訳は linux-x64 6,418,379、win32-x64 502,528、darwin-arm64 365,492、linux-arm64 310,992、darwin-x64 89,750、win32-arm64 62,834。版別の合計は `point/last-week` の値（15,057,834）と一致した。

読み方（事実）: `@openai/codex` という 1 つのパッケージ名のダウンロード数の約半分は、本体ではなくプラットフォーム別バイナリの版に付いている。npm の定義では 1 ダウンロード = tarball への HTTP 200 応答 1 回（[sources.md](sources.md)）なので、本体とバイナリの 2 つの tarball が同じ名前の下で 2 回に数えられている、という予測と合う。
同じ集計を他の 2 つに当てると、プラットフォーム接尾辞つきの版は 0（Claude Code はバイナリを別名の 8 パッケージに置き、Gemini CLI はバイナリを持たない）。

- Homebrew の内訳: Claude Code = cask `claude-code`（29,636 / 189,175 / 1,125,985）＋ `claude-code@latest`（5,928 / 25,825 / 82,893）、Codex CLI = cask `codex`、Gemini CLI = formula `gemini-cli`
- 予測「順位は一致しない」は、30 日と 90 日では**外れた**（一致）。365 日では不一致
- formula `codex`: Homebrew の API は 404 で、取得前に決めた方法（メタデータの homepage）では確認できなかったため、上の表には足していない。取得後に homebrew-core の履歴で OpenAI の Codex だと確認した（2025-10-17 に cask へ移行のため削除）。足した場合の 365 日は Codex CLI 843,515 で、順位は Claude > Codex > Gemini。**どちらでも npm とは不一致**で、30 日・90 日の一致も変わらない（[posthoc.md](posthoc.md) 5 節）
- Homebrew の数は analytics を無効にしていない利用者の install イベントで、利用者数ではない
