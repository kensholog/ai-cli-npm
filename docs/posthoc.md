## 6. バイナリの数え方の違いを並べる

| | 本体 | プラットフォーム別バイナリ | バイナリ ÷ 本体 |
|---|---:|---:|---:|
| Claude Code（30 日） | 61,861,381（`@anthropic-ai/claude-code`） | 67,940,446（**別名**の 8 パッケージの合計。本体の数には入らない） | 1.098 |
| Codex CLI（直近 7 日） | 7,283,980（安定版） | 7,749,975（**同じ名前**のプラットフォーム版。本体の数に入る） | 1.064 |
| Gemini CLI | ── | バイナリなし | ── |

- どちらも「本体 1 回につきバイナリがほぼ 1 回」で、違いはバイナリが**どの名前の下で数えられるか**だけ。Codex CLI は同じ名前なので、パッケージ名の合計が約 2 倍になる
- バイナリのうち Linux の割合は Claude Code 76.7%（30 日）、Codex CLI 86.8%（直近 7 日、linux-x64 ＋ linux-arm64）。デスクトップの OS の比率とはかけ離れており、CI やコンテナでのインストールが多いことを示唆する（推測。ダウンロード元の内訳は公開されていない）
- 試算（**仮定つき**。直近 7 日の s = 0.5147 が 30 日間ずっと同じだったと仮定）: Codex CLI の 30 日 78,292,095 からプラットフォーム版の分を除くと約 3,800 万で、Claude Code の本体 61,861,381 を下回る。つまり **npm の 30 日の順位は、プラットフォーム版を数えるかどうかで入れ替わる**。これは「どちらが多く使われているか」の主張ではない（npm 以外の経路があり、ダウンロード数は利用者数ではない）。「数え方をそろえないと順位すら決まらない」ことの例
