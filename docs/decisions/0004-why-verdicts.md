## 記事で言えること・言えないこと

言える（事実）:
- 海外で「Codex が npm で Claude Code の 12 倍」と報じられた週、Codex CLI の npm は直前 4 週の 49 倍だったが、issue・初めて issue を立てた人・Hacker News は 1.2 倍前後、GitHub Releases は 1.7 倍だった。関連する npm パッケージも 1.1〜1.2 倍。突出は 05-07 に平常へ戻った
- 人の指標が実際に動いたのは、その 1 週前（04-23 の週。OpenAI の変更履歴に GPT-5.5 の項目がある週）で、1.3〜1.6 倍だった（事後の確認）
- 同じ時期に Claude Code の issue と Hacker News の投稿は減っている（issue 作成者は 4 月 → 5 月で 30% 減。事後の確認）。**これは Anthropic に不利な事実だが、0003 の規律どおり併記する**
- 2026-01 → 08 で、Codex CLI の代理指標は 2.2〜6.8 倍に伸びた。npm は数え方を除いても 17.6 倍

言えない:
- 突出の原因（始まりが 0.128.0 の公開日と一致する、までしか分からない）
- どのツールの利用者が多いか、利用者が実際に移ったか（issue は利用者数ではなく、減った理由も分からない）
- npm の伸びのうち、代理指標で説明できない残り（算術で約 2.6 倍）の中身
